# LOOP — Customer Feedback Intelligence
Listen. Understand. Act.
LOOP is an AI-powered customer feedback intelligence platform that helps teams collect, organize, analyze, and understand customer feedback in one place.

## Live Demo
[LOOP — Live Demo]( https://project-loop-theta.vercel.app/login )

## Project
Developed as part of the Zidio Development Web Development Internship — Batch 6.2.
- Team: Team 03

## Features
- Authentication with OTP verification
- Workspace-based multi-tenant architecture
- Role-based access control
- Dashboard analytics
- Feedback management
- CSV Feedback Import with validation and corrections
- AI-powered Feedback Studio
- Trends and theme analysis
- Ask LOOP — natural-language feedback Q&A
- Voice of Customer reports with PDF export
- Workspace Themes & Channels
- Feedback trash management
- Google Forms feedback integration

## Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Charts: Recharts
- Backend: Next.js API Routes
- Database: PostgreSQL with Neon
- ORM: Prisma
- Authentication: NextAuth / Auth.js
- AI: Groq API
- Validation: Zod
- Deployment: Vercel
- Version Control: Git & GitHub

## AI Features
### Feedback Studio
Analyzes customer feedback and identifies useful patterns and insights.
### Trends
Helps identify recurring themes and changes in customer feedback.
### Ask LOOP
Allows users to ask questions about their feedback in natural language and receive answers based on available feedback data.
### Reports
Generates Voice of Customer reports using actual workspace feedback, including summaries, themes, insights, and recommendations.
## Security
LOOP uses workspace-level data isolation and role-based access control so users can only access data belonging to their workspace.

- Database: PostgreSQL with Neon
- ## Database
LOOP uses PostgreSQL with Neon for database storage.
